1. Internet Overview

The Internet is a worldwide network of interconnected computers and devices. It allows users to communicate, share information, access websites, send emails and use online services.

2. Fundamental Computer Network Concepts

A computer network connects two or more devices so that they can exchange data and share resources.

  • IP Address: Identifies a device on a network.
  • Router: Directs data between different networks.
  • Protocol: Set of rules used for communication.
  • HTTP/HTTPS: Protocols used for web communication.
  • DNS: Converts domain names into IP addresses.

3. URL and its Structure

URL stands for Uniform Resource Locator.

https://www.example.com/products/index.html
  • https: Protocol
  • www: Subdomain
  • example.com: Domain name
  • /products: Directory
  • index.html: Web page

4. Domain Name

A domain name is the human-readable address used to access a website. For example, google.com is a domain name.

5. Web Browser and Web Server

A web browser is software used to access websites. A web server stores website files and sends them to the browser when requested.

6. Working Principle of a Website

  1. User enters a URL in the browser.
  2. DNS finds the server's IP address.
  3. The browser sends a request to the server.
  4. The server processes the request.
  5. The server sends a response.
  6. The browser displays the webpage.
User → Browser → DNS → Server → Response → Browser → Website

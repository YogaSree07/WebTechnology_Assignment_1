## About the Project

This repository contains the solutions for Web Technology Assignment - I. The assignment demonstrates fundamental concepts of HTML5, CSS3, and JavaScript through five practical web development programs.

## Questions Covered

### Q1 - World Wide Web Concepts

A webpage explaining:

* Internet Overview
* Fundamental Computer Network Concepts
* URL and its Structure
* Domain Name
* Web Browsers and Web Servers
* Working Principle of a Website
* Client-side and Server-side Scripting

### Q2 - Student Admission Form

A responsive admission form demonstrating:

* HTML Form Elements
* Different Input Types
* Image, Video and Audio
* CSS3 Selectors
* CSS Box Model
* Responsive User Interface

### Q3 - Fashion Store Homepage

A fashion store homepage demonstrating:

* Backgrounds and Borders
* Text Effects
* CSS Animations
* Multiple Column Layout
* User Interface Design Principles

### Q4 - Student Grade Calculator

A JavaScript program that calculates:

* Total Marks
* Average
* Grade
* Pass/Fail Status

The program accepts marks for five subjects.

### Q5 - Supermarket Bill Calculator

A JavaScript program that:

* Accepts quantity and unit price for three products
* Calculates the total bill
* Applies a 10% discount when the total exceeds ₹2000
* Displays the final payable amount

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open any question folder.
4. Open its `index.html` file.
5. Right-click and select **Open with Live Server**.
6. View the output in the web browser.
